- `ds_fetch_prefix` drops `--retry` because retries cannot safely rewind output sent to stdout. A failed fetch exits non-zero and leaves no file, so re-running is safe (idempotent).

RISKS:
- OpenAlex may hold more than one source for the same venue, for example per-year proceedings sources. If so, the per-venue OpenAlex counts, and therefore the estimate, are biased low. This is recorded in the manifest; it is not measured.
- On curl versions older than about 8.4, `--max-filesize` may not stop a transfer whose length is not announced. `head -c N` still caps the bytes written to disk at N. Network bytes can then exceed N until curl gets a write error, but the transfer stops soon after N.
- Trimming still differs between dslib and Scala: Python `str.strip()` removes Unicode whitespace, while Java `String.trim` removes code points up to U+0020. This was out of scope for finding 13 (digits only) and is unchanged; raise it as a follow-up if exact parity is wanted.
